# Fortune Cookie Wisdom for Developers

A make.fun entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/competitions/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) competition.

## What it does

`main.py` (Python 3.13, standard library only) writes one original line of fortune-cookie wisdom aimed at a software developer to `/output/entry.txt`:

> Your future self is already reading this code at 2 a.m.; write the comment you wish you had found.

## Run

```sh
python3 main.py
```
